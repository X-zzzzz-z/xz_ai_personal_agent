# 学习记录工具的错误处理

- 学习日期：2026-10-05
- 关键词：学习记录、参数校验、JSON、异常处理

## 为什么需要错误处理

如果用户传入错误参数，或者数据文件出现问题，程序可能中断，也可能写入错误的数据。

## 参数校验

这里用自己的话记录：
- 日期格式需要检查是否符合YYYY-MM-DD的格式。
- 标题和内容必须是非空字符串。

## 读取数据时的异常

这里分别解释：
- 文件不存在：`open()` 读取不存在的文件时，会出现 `FileNotFoundError`。
- JSON 内容损坏：`json.load()` 无法解析内容时，会出现 `JSONDecodeError`。
- JSON 最外层不是列表：辅助函数会主动抛出 `ValueError`。

## 添加和查询的不同处理

文件不存在时，把它当作目前0条记录，所以使用空列表[]继续执行，后面写入时才会创建。
文件不存在说明没有可查询的数据，所以应该返回错误提示，不能假装存在一个空文件。

## 我的理解

函数首先检验用户传入的参数，然后调用辅助函数读取学习记录。读取正常时，继续完成添加或查询；读取出异常时，会立即进入对应的except。添加函数只有在文件不存在时才使用空列表继续执行，其他读取异常会直接返回；查询函数遇到读取异常时会直接返回错误信息。
